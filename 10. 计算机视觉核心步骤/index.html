这节课一开始，咱们又到图像分类了。用图像研究这个问题，数字识别。

我们看一下下面的图。

我给了三张图片，三张图片一个是数字 8，一个是数字 1， 一个是数字 6.这三张图片都是 6*6 的矩阵。

那么我们看一下，咱们从第一节课到现在，学了那么多的图像处理的方法。那么如何对这三张图片进行分类呢？如何对它进行识别。如何识别出第一张图片上的数字是 8，第二张图片上是 1，第三张图片是 6。

大家可以想一下，好好想个几分钟。想想，我如何把这 3 张图片完成分类呢？用图像处理的方法能不能做，如何去做。

大家在想的过程中，我可以给大家一些引导。

注意下图像识别，要知道这个图像是 8、是 1、是 6，要如何把它计算出来？那实际上我们发现我们是要完成一种映射的，也就是说我们的 6*6 这个矩阵要把它映射为一个 ID，一个值，第一类、第二类、第三类。其中，第一类是 8，第二类定义为 1，第三类定义为 6。

也就说这个图片本身是什么不重要，关键是要把这三个图片分成三个类别。我们关键是要把这个图片分好类，三个类别分别人工定义对应 8，1，6，它是一种影射。

所以，等于说关键是完成数字上的一种影射。就是把 6*6 的矩阵影射为一个 ID，这个ID 是 0、1、2， 或者是1、2、3，反正要分成三类，每个类有一个 ID 是对应着的。

我们等于是想完成一个 function，一个函数。函数输入是 Matrix，输出是 ID。id = Function(Matrix)。

这个矩阵输入进来之后，我希望这里得到一个数字。在这个函数中，我们输入数字 8 的这个矩阵，我希望输出 id=1，输入数字 1 的矩阵，我希望输出 id=2，如果是数字 6 的矩阵，我希望输出 id=3。也就是 y = f(x) 这样的一个映射。

实际上你看，图像分类或者图像识别好像是很困难的事情，当我们把它数学化，用数学的思路去讲它，实际上它就是完成一个函数而已。这个图片作为函数的输入，输出是一个分类的 ID 就行了。

一个 6*6 的矩阵中有 36 个数字，36 个数字映射为 1 个数字。具体的就是把这个36个数字映射为 1 类。所以它其实就等于是我们需要完成一个函数或者是完成一个公式。

在这样的基础上再去设计一下，再去想一下。

这里我们就要求计算机要像人一样去判断数字。那么计算机像人一样判断该怎么去做呢？它只有通过计算，就是刚才我们的函数这样。这样就好像计算机也拥有了视觉的功能一样了对吧？

好，这个问题怎么解决大家可以去想一下。总体上还是说要把矩阵对应成一个数字，分类只是对应成一个。具体怎么对应大家可以想一下。

在大家想的时候，我先介绍一下其他内容。

计算机视觉总体上可以分为以下四大问题：

第一类就是分类问题。人脸识别，OCR 识别等等就属于分类问题。

第二类就是目标检测问题，检测问题实际上就是定位问题。就检测到这个图片上的人脸的位置、检测到这个图片的文字的位置等等。

第三个问题就是分割问题。比如说我们人脸区域的分割，还有个项目叫车道线的分割，还有一些其他的分割，其实就是精细轮廓的意思。

第四个是描述问题。描述问题其实现在应用的比较少，或者说这个性能还有待提升，所以我们通常不说它，通常就说三大问题。描述问题具体的是看图说话。就是给一张图片时候，我们人能看到这个图片上是什么，是个 PPT，是个汽车等等。轮到计算机，这个模型也会输出这样的一段话来。

对于这个4大问题数学上该如何表示，或者计算机该如何去完成任务。

计算机输入是图片视频是吧？那表现在数据上它就是矩阵。输入是矩阵，输出是什么呀？

对于分类问题，输出当然是类别号 ID，一个数值。

对于位置，我们位置通常用矩形表示，比如说人脸在什么位置，我们用矩形框出来。通常用矩形的左上角点、矩形的宽、矩形的高来表示。左上角点的坐标是 (x,y)。所以说我们通常表示一个矩形就用 4 个数值，x、y、w、h 来表示。这个我们又称为 bounding box，就是轮廓 box。bounding box 就是 4 个值。

所以位置等于我们把一个矩阵映射为 4 个值，就是矩阵。比如说我们刚才 6*6 的矩阵，36 个值映射为 4 个值。再比如我们这个矩阵大一点，如果是 320*640这么多个数值，也把它映射为 4 个数值。这就是我们计算机中的模型要解决的事情。它要建立一个模型去解决这个事情。

精细轮廓其实就是画一个多边形，多边形有多个点，把多个点连起来。很多点就是很多个点的坐标了，比如说 n 个点，就是 n 乘 2 个数值了。

一句话呢？每句话其实都可以是向量，这里提一嘴，大家可以看看我之前写的关于 Embedding 的相关文章。

精细轮廓除了很多点表示，还可以用一个黑白点的 2 值图来表示。也就是，可以用 mask，也可以用多边形，就用 2 值图来表示。mask 就是遮罩图。

所以，计算机视觉的所有问题，刚才咱们说的 4 大问题，它都是输入矩阵，输出都是数字。ID是 1*1 的矩阵，binding box 是 1*4 的矩阵。

这样也就是说，我们整个计算机视觉的模型，它输入是个矩阵，输出还是个矩阵。只不过计算机视觉输出的矩阵其实是有一定的意义的，要么是某个类别，要么是它表示位置。它不像图像处理输出的还是表示图片，图片没有判断意义，或者判断意义不明显。这就是计算机视觉和图像处理的一个不同。

所以，计算机视觉要求的计算就多一些，巧妙一些。

那么，再回到我们刚才这个问题，针对图片的分类问题，你会以何种方式给予计算机视觉的功能？会把这个 6*6 的 Matrix 怎样的变成 1*1 的ID。针对这样的图片，如何把这个值影射为1、2、3，如何解决这个影射问题。

这个影射的计算过程我们称为模型计算，把这个 6*6 的矩阵输入到这个模型中，模型输出一个 ID 矩阵。那么如何去设计这个模型内部的计算过程呢？

直接判断可以吧？如果当前输入的矩阵是等于 8 的这个矩阵，这个我们是知道的，那么我就 return 8，就是直接输出了一个结果数字， return 1 呢，就是输出了第一类的 ID。

也就是说我的模型可以简单到直接判断，直接比对就行了。这实际上就是模板匹配的基本思路，就是比较。于是我准备了几个模板，分别准备了 8、1、6 的这几个模板，就看你输入的这个矩阵它到底是等于几，然后我就返回几。这是直接判断对吧？这是最简单的模型，或者不能称之为模型。

我们可以称它为模型是因为它能完成判断功能，那我们为什么又不能称它为模型呢？因为这个模型不是学习来的，是我们人工指定的。人工指定的就有写固定程序的嫌疑了，它就不是学习的。

那么模型到底是要学习什么呢？其实我们要对这个矩阵判断，判断它到底属于那个类别的时候我们依赖的那些数值和参数。

我们要对矩阵进行判断，是依赖于这三个模板：matrix 8、matrix 1、matrix 6，这三个模板是已知的对吧？也就是说，这三个模板是我们模型的参数，我们模型要依赖这些参数才能对矩阵进行判断。

模型的参数如果是已知的，那这种模型其实上它就不用学习了。不过我们后面要学习的基本上模型的参数是要学习出来、要求解出来的。也就是说我们的模型就是需要我们根据样本情况，根据实际情况、实际数据去学习到的。

现在这三个模板我们可以直接判断，就好像是直接把数据拿过来没有任何加工，没有任何计算而得到的。这就是一个最简单的模型了。

那么通过这种直接判断，我们是可以对三张图片进行识别、进行分类。现在，再加深一些难度。刚才是 3 张图片，现在如果是 10 张图片呢？10 张 6*6 的图片如何实现分类呢？那是不是我这个 if else 写 10 次判断就行了？虽然笨，但这就是模板匹配的方法，这种方法其实也可以。

所以到这里我们稍微总结一下图像处理和计算机视觉的区别。

图像处理其实更强调是 Matrix 到 Matrix，两个都是 Matrix，但图像处理只是单纯的 Matrix 到 Matrix，输出的这个 Matrix 它仍然还是表示图片。

那计算机视觉呢？也是 Matrix 到 Matrix，但输出这个 Matrix 就表示一个决策的结果了。

分类问题就是一个 ID，检测问题就是 1*4 的 Matrix，或者是 n*4 的 Matrix，因为 n 个目标要检测。如果是分割问题，它就是别的 Matrix，也就是要有个 Matrix 代表决策结果。

当然，计算过程会有些差异，但是计算过程具体的差异是因为它的目标不同。这是图像处理和计算机视觉的区别。那么这里决策部分，就相当于计算机像人一样去判断。也就是说，计算机视觉是相当于图像处理加上判断，用图像处理的方法去做一些判断，基本上就这样的思维。

好，接着我们上面的问题，刚才我说如果有 10 个数字，就可以写 10 个 if else 就行了。那么现在问题又变了，如果图片多了呢？100 张、1,000 张、1 万张、10 万张图片需要判断，难道还是写 if else？那写代码就没什么意义了，你要写成千上万个 if else，那写出来... 对吧？屎山啊。

所以我们这里需要什么？需要把这个模型重新设计。怎么解决这个问题呢？假设我们现在有 100 张图片，数字 1 可能有 10 多张：

这 10 多张的数字 1，分布的位置都各不相同。有的大一些，有的小一点，有的偏左，有的偏右。就各个图片上的数字的位置和大小都不同，这时候你会发现我们要是还是写模板用匹配法，模板数量也要增加，1 万张图片就有 1 万个模板。这样的模型的参数量就太大了，不合适。

这时候我们通常怎么办呢？我们利用图像处理的方法对图片进行处理，其实有几种方法。我们就希望设计出一种变换，原图变换，对图片进行变换之后，图片原来这种 Matrix 还是变成 Matrix，或者变成 Vector，比如说 1*256 的向量。

这样的话我们的图片不直接参与决策，设计一个 Vector 代表图片进行决策。也就是说，原来 if else 的时候用的是图片本身的 Matrix，现在不了，我利用图像处理的方法对每个图片的 Matrix 提个特征，或者对它处理一下，处理得到一个 Vector。这个向量是 1*256 的向量。图片处理成向量之后，向量和向量之间做对比，而不是图片做对比。

为什么要对向量做对比呢？我是希望利用图像处理的方法，无论这个 1 大小如何变，位置如何变，这个 1 提到的特征或得到的这个 Vector 都是一致的，都是同一个向量。

举个例子，比如说我就取这个图片的直方图作为向量。

比如说上图中第一个 1，变换为矩阵的话，白色是 0，黑色是 1。那么它的直方图是什么？因为它只有 0，1 两个像素值，两个灰度级，所以直方图就两个值。0 有多少个？我们可以先取数一下 1 有多少个，应该是有 8 个，那 0 就是 36-8 = 28 个，这就是它的直方图。然后再归一化一下，[28/36, 8/36]，就是它的 1*2 这个向量了。

由原来 36 个像素，我给它提一个特征，提到一个直方图，统计一下它灰度值的取值情况。就得到这样的 1*2 的向量来代表这个图片。

那对于第二张 1 的图片呢，我们就可以到到 [27/36, 9/36]。然后第三张 1 的图片也是 [28/36, 8/36]。

这样统计下来你会发现，这个 1 无论它是如何去变化，虽然这个 1 在图片的位置不同，但是我提到的特征基本是一致的。即便因为大小问题提取到两个不同的 Vector，但是做判断的时候也比十几个不同的模板要小很多，这个模板的数量可以减少很多。这一下就大大简化我们的问题了。

这就是用图像处理对图像进行提特征，提特征之后再去判断。

刚才提到一个直方图我们就发现无论 1 的位置如何变化，我们特征基本不变。其实我们希望还希望无论 1 的大小如何变化，我们特征不变。我们发现这个 1 大小改变之后这个特征是有所变化，虽然变化不大，但仍然是有所变化的，那么这个特征就提的不好。

用直方图相对来说，1 的大小改变了它就改变了，不是太完美。那其实我们理论上是希望我们无论 1 的大小如何变化，我们提到的特征是不变的。更深一步就是，无论我们 1 的角度如何变化，就算 1 在图片上是斜着的，是倒着的，我们特征都是不变的。

再深一点去考虑，我们现在是灰度图，就只有 0,1 两个值。那之后会有彩色图像，它颜色如何去变化，特征也能保持不变。当我们特征有这么多不变性之后，我们就可以直接做出判断，做出决策了。

就是说，如果我们设计的这个特征，在利用图像处理对图片提取特征之后能够把图片的核心特征提出来，该特征具有各种不变性的特征。如果特征提的好的话，我们决策函数就可以还用直接判断，就非常简单了。

所以说，我们这里对图像提取特征的这个技术在计算机视觉中是非常重要的一个步骤。提取完特征后再加上一个判断，判断出结果就行了。

所以计算机视觉它包含了两步，一个是提取特征，提取特征这一步用的是图像处理的方法。二是进行判断，计算视觉就等于图像处理加上判断。判断就是个 function，是一个函数，也就是我们的模型。

至此，我们可以得到一个结论： 图像处理 + model = 计算机视觉。
